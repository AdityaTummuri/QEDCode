# QEDCode logo

The mark is `<∎>`: code brackets around the end-of-proof square ("Q.E.D."), filled in the green of a
passing test.

| File | Use |
| --- | --- |
| `logo-light.svg` | Mark and wordmark, for light backgrounds |
| `logo-dark.svg` | Mark and wordmark, for dark backgrounds |
| `mark.svg` | Square app icon (avatar, favicon, social preview) |

Colours: ink `#1f2328` (light) / `#e6edf3` (dark), green `#2ea043`, icon background `#0d1117`.

The artwork is original to this project: two strokes and a square, and a wordmark set in the
viewer's system font. It uses no third-party images, icons or font files. The end-of-proof square
is a long-standing mathematical symbol that anyone may use.
